# 项目流程管理

可自行填写的项目与清单模板框架，支持两种排版。

首次打开没有预置内容。项目、模板、方格标题、待办和备注均由使用者添加，保存在当前浏览器中。发布文件不包含浏览器中填写的数据。

- 左侧项目列表显示当前阶段和进度，顶部按清单分别显示当前阶段与下一项。
- 模板增删改同步到关联项目；被删除但已有完成记录、备注或日期的内容保留为“已停用”，不计入进度。
- 顶部可撤销本次打开期间最近20步内容修改；刷新后撤销历史清空。
- 两种框架支持只看未完成，以及可选截止日期；临近3天或逾期时显示提醒。
- “数据与备份”统一识别项目、模板、XMind和施工图备份，可导入为项目、模板或现有项目中的清单。旧版16列备注合并为12列，保留全部文字。
- 顶部“☁ 同步”沿用原来的 Firebase 同步服务，各设备使用同一个同步码即可自动同步，项目、模板、打卡进度和备注分别合并。默认仍只保存在本机，点击“连接并合并”后才启用。

验证：`node tests/workspace.cjs`

同步配置和实现说明见 [cloud/README.md](cloud/README.md)。同步码不随备份文件导出，也不会写入发布源码。

构建同步组件：安装依赖后运行 `npm run build:sync`。验证全部功能：`npm test`。

新增便捷操作：

- 顶部“进行中”和“下一项”可点击，定位并高亮对应节点、待办或施工图卡片；桌面端在内容区滚动，顶部操作区始终可见。
- 左侧已完成项目默认折叠，搜索定位时会自动展开。
- 全局搜索（⌘K / Ctrl K）覆盖项目、清单、节点、待办和备注，包括施工图页面备注，结果区分项目与模板。
- 模板增删改会在关联项目中显示简短提示；明细和已读状态保存在各自设备，远端模板更新也会提示。
- 同步成功显示本机最近确认时间，断网显示“本机已保存 · 等待同步”，可查看上次同步时间。

模板编辑页会明确提示“完成打卡请进入项目”，可用“去项目中打卡”打开已有项目清单；项目内点击待办内容或勾选框会完成并高亮。同步元数据缓存使用压缩保存，兼容已有的普通 JSON 缓存。


## 与项目排期联动

流程管理与 https://sange0613.github.io/project-checkin-dashboard/ 使用同一同步码。排期页编辑一个阶段项目，将“阶段来源”设为“跟随流程管理”，选择对应项目与一份设计清单。关联信息会通过原有同步服务同步到其他设备。

实际阶段、下一项和进度由这份清单决定；其他清单独立。节点右侧可填计划开始、计划结束，排期页的当前任务条自动跟随。没有日期时显示待排期，不沿用前一阶段日期；总设计周期与排期备注仍由排期页维护。点击“查看流程”定位当前待办。切回手动模式可继续使用原手动排期。

`flowline-reader.js` 由 `npm run build:sync` 生成，是给排期页使用的只读订阅组件：复用加密同步数据，只输出项目、清单、节点、待办和日期的摘要，不写入云端。实际日期仅记录新发生的勾选或状态操作，旧数据不补造日期。

## 卡片添加范围与停用恢复

在关联了模板的项目中添加节点、大卡片、待办小卡片或 2 号框架图纸，可选择：

- **只加到当前项目**（默认）：这张卡片属于当前项目，不会进入模板或其他项目；同一项目在其他设备上仍照常同步。模板之后更新，也会保留这张项目专属卡片。
- **同时加入模板并同步其他项目**：把新卡片内容加入当前清单的关联模板，再分发给使用此模板的项目。已有项目的打勾、项目日期和备注保持独立，模板及其他项目不会继承本项目的完成状态。

在模板库添加卡片，继续自动分发到关联项目。没有关联模板的项目，仅可添加到当前项目。

模板删除卡片后，有历史进度或备注的内容保留为“已停用 · 保留记录”，不计入进度。1 号框架点击“恢复使用”，2 号框架点击停用卡片后选择“恢复并保存”，即可保留原完成状态与备注并重新启用；恢复时同样可以选择只在本项目使用，或重新加入模板。只看未完成时会隐藏停用记录，恢复前需关闭该筛选。
